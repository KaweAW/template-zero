## npm dependencies

The packages listed in `package.json` are not redistributed in this repository. At the time of
writing, all direct dependencies use permissive licences (MIT, Apache-2.0, or OFL-1.1 for the fonts
above). When you install them, each package brings its own licence file in `node_modules/`.

If you add a dependency, check its licence before shipping a client site.

## Images

Everything under `public/images/` is generated by `scripts/generate-placeholders.ts` from scratch
(gradients and shapes). It contains no third-party artwork. Replace it with the client's own photos.
